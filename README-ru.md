# Hedgehog RP Map
> **Основной проект:** [hedgehog-rp](https://github.com/MaSStiK/hedgehog-rp)

**Hedgehog RP Map** - интерактивная карта мира ролевой вселенной Hedgehog RP с поддержкой просмотра текущей версии карты и архивных карт прошлых сезонов.

Проект предназначен для отображения государств, изменений границ, политических процессов и эволюции игрового мира на протяжении всей истории проекта.

## ✨ Возможности
- Просмотр актуальной карты мира
- Доступ к архивным картам прошлых сезонов
- Отслеживание изменений границ и политической обстановки
- Масштабирование и удобная навигация по карте
- Переключение между сезонами проекта

## 🔗 Связанные проекты
- 🦔 [Hedgehog RP](https://github.com/MaSStiK/hedgehog-rp)
- 📺 [Ежиное телевидение](https://github.com/MaSStiK/tv.hedgehog-rp)
- 📊 [Статистика беседы](https://github.com/MaSStiK/stats.hedgehog-rp)

## 🛠️ Технологии
- **React** - пользовательский интерфейс
- **react-dropdown-select** - выпадающие списки
- **react-zoom-pan-pinch** - масштабирование и перемещение карты
